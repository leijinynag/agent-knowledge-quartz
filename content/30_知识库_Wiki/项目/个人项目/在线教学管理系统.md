# 在线教学管理系统

## 一句话介绍

在线教学管理系统是一个基于 Vue3 + JavaScript + Pinia + Element Plus + Socket.io + Vite + Node.js 的教学管理平台，支持学生端、教师端、课程管理、作业系统、考试管理和实时通信。

## 背景与目标

传统教学管理效率低，师生互动不便。项目目标是构建一个前后端分离的可视化教学管理平台，覆盖课程、作业、考试、通知和在线状态等流程。

## 我的职责

根据简历截图，主要负责：

- 管理员端和学生端界面开发。
- 基于角色权限体系实现差异化 UI 展示。
- 路由守卫和动态菜单。
- Socket.io 实时通信。
- 性能优化：懒加载、防抖搜索、路由懒加载、虚拟滚动等。

## 技术架构

- 前端：Vue3、JavaScript、Pinia、Element Plus、Vite。
- 后端：Node.js。
- 实时通信：Socket.io Client。
- 权限：JWT + 路由守卫 + 动态菜单。

## 面试讲述版本

### 1 分钟版

在线教学管理系统是我做的一个 Vue3 前后端分离项目，主要包括学生端、教师端、课程管理、作业和考试流程。我负责前端页面和权限体系，包括 JWT 登录、路由守卫、动态菜单，以及基于 Socket.io 的实时通信。项目中比较能体现工程能力的是权限系统和实时状态同步，同时也做了懒加载、防抖搜索、路由懒加载和虚拟滚动等性能优化。

### 3 分钟版

这个项目面向在线教学场景，核心目标是提升教师管理课程、作业、考试和学生互动的效率。前端使用 Vue3、Pinia、Element Plus 和 Vite，后端使用 Node.js，并通过 Socket.io 实现实时通信。

我主要负责两类能力：第一是权限和导航体系，基于 JWT 做登录态，前端通过路由守卫控制页面访问，通过动态菜单根据角色展示不同功能，并在 Axios 拦截器中统一处理 token 和 401/403。第二是实时通信能力，封装 Socket.io Client，支持消息推送、在线状态同步、断线重连和心跳检测。性能方面，我也做了前端懒加载、防抖搜索、路由懒加载和虚拟滚动，减少大数据量场景下的渲染压力。
