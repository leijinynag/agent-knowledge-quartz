# 函数柯里化

## 一句话定义

函数柯里化是把一个接收多个参数的函数，转换成可以分多次接收参数并最终执行的函数包装技术。

## 核心要点

- 依赖闭包保存已经接收的参数。
- 用 `fn.length` 判断原函数声明需要的参数数量。
- 参数收集足够时执行原函数；不足时返回继续收集参数的新函数。
- 需要注意 `this` 绑定和剩余参数拼接。

## 原始实现摘要

原始代码在 `curry(fn)` 内返回 `curried(...args)`，当 `args.length >= fn.length` 时调用 `fn.apply(this, args)`；否则返回一个继续接收 `...rest` 的函数，并递归调用 `curried.apply(this, args.concat(rest))`。

## 推荐实现要点

```js
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn.apply(this, args)
    }
    return function (...rest) {
      return curried.apply(this, args.concat(rest))
    }
  }
}
```

## 边界情况

- 默认参数会影响 `fn.length`。
- 剩余参数函数的 `fn.length` 可能不是预期值。
- 如果需要占位符，如 `curry.placeholder`，实现会更复杂。
- 如果多次分步调用需要保留调用者 `this`，应明确 `this` 绑定策略。
