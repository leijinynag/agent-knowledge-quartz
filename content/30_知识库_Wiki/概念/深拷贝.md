# 深拷贝

## 一句话定义

深拷贝是递归复制对象内部嵌套结构，使新对象与原对象不共享可变引用。

## 核心要点

- 原始值和 `null` 可以直接返回。
- 数组和对象需要递归复制每个元素/属性。
- 循环引用需要用 `WeakMap` 记录“已复制对象 → 新对象”。
- 面试中要主动说明支持范围和不支持范围。

## 原始实现摘要

原始实现 `deepClone(obj, map = new WeakMap())`：

- 非对象或 `null` 直接返回。
- 如果 `map` 中已有对象，返回缓存结果，避免循环引用。
- 数组逐项递归复制。
- 普通对象使用 `for...in` 遍历自有属性并递归复制。

## 推荐实现要点

原始版本适合作为基础版：

```js
const deepClone = (obj, map = new WeakMap()) => {
  if (obj === null || typeof obj !== 'object') return obj
  if (map.has(obj)) return map.get(obj)

  if (Array.isArray(obj)) {
    const newArr = []
    map.set(obj, newArr)
    for (let i = 0; i < obj.length; i++) {
      newArr[i] = deepClone(obj[i], map)
    }
    return newArr
  }

  const newObj = {}
  map.set(obj, newObj)
  for (const key in obj) {
    if (Object.prototype.hasOwnProperty.call(obj, key)) {
      newObj[key] = deepClone(obj[key], map)
    }
  }
  return newObj
}
```

## 已覆盖范围

- primitive values
- `null`
- 数组
- 普通对象
- 循环引用

## 未覆盖范围

- `Date`
- `RegExp`
- `Map`
- `Set`
- `Symbol` keys
- 不可枚举属性
- 属性描述符
- 原型保留
- 函数
- class 实例
- DOM 节点

## 面试讲解要点

- 一定要提 `WeakMap` 处理循环引用。
- 一定要主动说明“这是基础版，不是完整结构化克隆算法”。
- 若追问完整性，可讨论 `structuredClone` 和它的限制。
