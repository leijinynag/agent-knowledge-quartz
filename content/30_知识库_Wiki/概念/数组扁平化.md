# 数组扁平化

## 一句话定义

数组扁平化是把嵌套数组递归展开为一维数组的过程。

## 核心要点

- 遍历数组中的每一项。
- 如果元素仍是数组，则递归展开。
- 如果元素不是数组，则直接放入结果。
- 可以用递归、栈、`reduce` 或原生 `flat(Infinity)` 实现。

## 原始实现摘要

原始实现创建 `result`，使用 `for...of` 遍历数组。如果 `item` 是数组，则递归调用 `flatten(item)` 并用展开运算符合并；否则直接 `push`。

## 推荐实现要点

```js
function flatten(arr) {
  const result = []
  for (const item of arr) {
    if (Array.isArray(item)) {
      result.push(...flatten(item))
    } else {
      result.push(item)
    }
  }
  return result
}
```

## 边界情况

- 嵌套很深时递归可能造成调用栈溢出。
- 稀疏数组的空位处理需要明确。
- 是否只展开指定层数，而不是无限展开。
- 是否保留非数组但类数组对象。

## 面试讲解要点

- 递归版本最直观，适合讲清楚“遇数组继续展开”。
- 若追问性能或深层嵌套，可改用显式栈。
