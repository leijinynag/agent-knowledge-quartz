# 事件循环与宏任务微任务

## 30秒回答

JavaScript 是单线程执行的，事件循环负责协调同步代码、宏任务和微任务。一次循环中，先执行一个宏任务中的同步代码，然后清空微任务队列，再进入渲染或下一个宏任务。常见宏任务有 `setTimeout`、`setInterval`、I/O、UI 事件；常见微任务有 `Promise.then`、`queueMicrotask`、`MutationObserver`。

## 执行顺序

```text
执行一个宏任务
  ↓
执行同步代码
  ↓
清空所有微任务
  ↓
必要时浏览器渲染
  ↓
执行下一个宏任务
```

## 示例

```js
console.log('script start')

setTimeout(() => console.log('timeout'), 0)

Promise.resolve().then(() => console.log('promise'))

console.log('script end')

// script start
// script end
// promise
// timeout
```

## 面试官可能追问

### 为什么 Promise.then 比 setTimeout 先执行？

`Promise.then` 回调进入微任务队列，`setTimeout` 回调进入宏任务队列。当前宏任务结束后会先清空微任务，再执行下一个宏任务。

### 微任务会不会阻塞渲染？

会。如果微任务不断追加微任务，浏览器可能无法进入渲染阶段，造成页面卡顿。

### async/await 和事件循环有什么关系？

`await` 后面的代码可以理解为被放入 Promise 的微任务回调中。相关：[[30_知识库_Wiki/概念/JavaScript/Promise与async-await]]。

## 常见错误回答

- 只说“异步先进队列”，不区分宏任务和微任务。
- 认为 setTimeout 0ms 会立即执行。
- 忽略微任务会在下一个宏任务前全部清空。
