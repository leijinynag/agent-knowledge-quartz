# 浅拷贝与深拷贝

## 30秒回答

浅拷贝只复制对象第一层属性，如果属性值是引用类型，复制的是引用；深拷贝会递归复制嵌套对象，尽量让新对象和原对象不共享可变引用。浅拷贝常用展开运算符、`Object.assign`；深拷贝可以用递归、`structuredClone` 或库函数，但要注意循环引用和特殊对象类型。

## 浅拷贝示例

```js
const obj = { a: 1, b: { c: 2 } }
const copy = { ...obj }

copy.b.c = 3
obj.b.c // 3
```

## 深拷贝关注点

- 普通对象和数组。
- 循环引用。
- Date、RegExp、Map、Set。
- Symbol key。
- 原型和属性描述符。
- 函数和 DOM 节点通常不适合简单深拷贝。

## 面试官可能追问

### JSON.parse(JSON.stringify()) 有什么问题？

会丢失 `undefined`、函数、Symbol、Date 类型、RegExp、Map、Set，无法处理循环引用，也会改变一些特殊值。

### structuredClone 有什么特点？

浏览器提供的结构化克隆能力，可以处理很多内置类型和循环引用，但函数、DOM 节点等仍不可克隆。

### 手写深拷贝如何处理循环引用？

使用 `WeakMap` 记录已经克隆过的对象。相关：[[30_知识库_Wiki/概念/深拷贝]]。

## 常见错误回答

- 认为 `{...obj}` 是完全深拷贝。
- 直接说 JSON 方法万能。
- 不提循环引用和特殊对象类型。
