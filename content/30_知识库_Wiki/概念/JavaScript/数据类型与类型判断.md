# 数据类型与类型判断

## 30秒回答

JavaScript 数据类型分为原始类型和引用类型。原始类型包括 `string`、`number`、`boolean`、`undefined`、`null`、`symbol`、`bigint`；引用类型主要是 `object`，包括普通对象、数组、函数、日期等。类型判断常用 `typeof`、`instanceof`、`Array.isArray` 和 `Object.prototype.toString.call()`。

## 核心要点

- `typeof null === 'object'` 是历史遗留问题。
- `typeof function(){} === 'function'`。
- `instanceof` 判断原型链，跨 iframe 可能失效。
- `Array.isArray()` 判断数组更可靠。
- `Object.prototype.toString.call(value)` 可区分很多内置类型。

## 常见代码

```js
typeof 1                 // 'number'
typeof 'a'               // 'string'
typeof undefined         // 'undefined'
typeof null              // 'object'
typeof Symbol()          // 'symbol'
typeof 1n                // 'bigint'
typeof function () {}    // 'function'

Array.isArray([])        // true
Object.prototype.toString.call([]) // '[object Array]'
```

## 面试官可能追问

### 为什么 `typeof null` 是 object？

这是 JavaScript 早期实现的历史遗留问题，`null` 被错误地标记成对象类型，后来为了兼容性没有修复。

### `instanceof` 的原理是什么？

判断左侧对象的原型链上是否能找到右侧构造函数的 `prototype`。相关页面：[[30_知识库_Wiki/概念/手写 instanceof]]。

### 如何写一个更完整的类型判断函数？

```js
function getType(value) {
  if (value === null) return 'null'
  return Object.prototype.toString.call(value).slice(8, -1).toLowerCase()
}
```

## 常见错误回答

- 把 `null` 说成引用类型。
- 认为 `typeof` 可以准确判断数组。
- 忽略 `symbol` 和 `bigint`。
