# 闭包

## 30秒回答

闭包是指函数可以访问其词法作用域中的变量，即使这个函数在原作用域之外执行。它的本质是函数和其外部词法环境的组合，常用于封装私有状态、函数工厂、缓存和事件回调。

## 核心要点

- 闭包基于词法作用域，而不是调用位置。
- 外部函数执行结束后，只要内部函数仍被引用，相关变量就不会被垃圾回收。
- 闭包可以保存状态，也可能导致内存占用增加。

## 常见代码

```js
function createCounter() {
  let count = 0
  return function () {
    return ++count
  }
}

const counter = createCounter()
counter() // 1
counter() // 2
```

## 应用场景

- 封装私有变量。
- 函数柯里化：[[30_知识库_Wiki/概念/函数柯里化]]。
- once 函数：[[30_知识库_Wiki/概念/once 函数]]。

- 模块化和缓存。

## 面试官可能追问

### 闭包一定会造成内存泄漏吗？

不会。闭包只是让被引用的变量生命周期延长。只有当不再需要的变量仍被引用，无法释放时，才可能形成内存泄漏。

### 循环中闭包的经典问题？

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0)
}
// 3 3 3
```

原因是 `var` 是函数作用域，三个回调共享同一个 `i`。可以用 `let` 创建块级作用域。

## 常见错误回答

- 只说“函数里面返回函数”，没有说词法作用域。
- 把闭包等同于内存泄漏。
- 不知道闭包和事件回调、定时器、函数工厂的关系。
