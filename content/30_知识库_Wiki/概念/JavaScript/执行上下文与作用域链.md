# 执行上下文与作用域链

## 30秒回答

执行上下文是 JavaScript 代码运行时的环境，包含变量环境、词法环境、`this` 绑定等信息。作用域链用于变量查找：当前作用域找不到时，会沿外层词法作用域继续查找。变量提升是执行上下文创建阶段的结果，`var` 会初始化为 `undefined`，函数声明会整体提升，`let/const` 有暂时性死区。

## 核心要点

- 全局代码、函数调用、eval 都会创建执行上下文。
- 函数每次调用都会创建新的执行上下文。
- 作用域由代码定义位置决定，属于词法作用域。
- `var` 是函数作用域，`let/const` 是块级作用域。
- `let/const` 在声明前访问会触发 TDZ 错误。

## 变量提升示例

```js
console.log(a) // undefined
var a = 1

console.log(b) // ReferenceError
let b = 2
```

函数声明和函数表达式：

```js
foo() // ok
function foo() {}

bar() // TypeError: bar is not a function
var bar = function () {}
```

## 面试官可能追问

### 作用域链和原型链有什么区别？

- 作用域链用于变量查找，和词法作用域有关。
- 原型链用于对象属性查找，和对象原型有关。

### 为什么 `let/const` 也提升但不能访问？

它们会被创建在词法环境中，但在初始化前处于暂时性死区，访问会报错。

### 闭包和作用域链有什么关系？

闭包保存了函数定义时可访问的词法环境，因此函数在外部执行时仍能沿作用域链访问外部变量。相关：[[30_知识库_Wiki/概念/JavaScript/闭包]]。

## 常见错误回答

- 认为 `let/const` 不提升。
- 把作用域链和原型链混淆。
- 只背“变量提升”，但说不清执行上下文创建阶段。
