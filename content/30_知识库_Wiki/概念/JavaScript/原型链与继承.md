# 原型链与继承

## 30秒回答

JavaScript 的继承基于原型链。每个对象都有内部原型 `[[Prototype]]`，可以通过 `Object.getPrototypeOf()` 访问；函数有 `prototype` 属性，用于作为实例对象的原型。当访问对象属性时，如果对象自身没有，就会沿原型链向上查找，直到 `null`。

## 核心要点

- `obj.__proto__` 指向对象的原型，不推荐直接依赖。
- `Constructor.prototype` 会成为 `new Constructor()` 创建对象的原型。
- 原型链属性查找是向上查找，不会向下查找实例。
- `class` 本质上是基于原型机制的语法糖。

## 常见关系

```js
function Foo() {}
const f = new Foo()

Object.getPrototypeOf(f) === Foo.prototype // true
Foo.prototype.constructor === Foo          // true
Object.getPrototypeOf(Foo.prototype) === Object.prototype // true
```

## 面试官可能追问

### `prototype` 和 `__proto__` 区别？

- `prototype` 是函数对象上的属性，主要用于构造实例原型。
- `__proto__` 是对象访问其内部原型的历史访问器。
- 推荐使用 `Object.getPrototypeOf()` 和 `Object.setPrototypeOf()`。

### new 的过程和原型链有什么关系？

`new` 会创建新对象，并把新对象的原型指向构造函数的 `prototype`。相关页面：[[30_知识库_Wiki/概念/手写 new]]。

### instanceof 如何利用原型链？

`instanceof` 会沿左侧对象的原型链查找右侧构造函数的 `prototype`。相关页面：[[30_知识库_Wiki/概念/手写 instanceof]]。

## 常见错误回答

- 把 `prototype` 和 `__proto__` 混为一谈。
- 认为 `class` 是完全不同的继承机制。
- 忽略原型链终点是 `null`。
