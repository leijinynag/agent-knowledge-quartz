# 模块化

## 30秒回答

JavaScript 模块化用于拆分代码、隔离作用域、复用能力。常见规范有 CommonJS 和 ES Module。CommonJS 主要用于 Node.js，运行时同步加载，导出的是值的拷贝或对象引用；ES Module 是语言标准，支持静态分析、编译期依赖解析和 tree-shaking，导出是 live binding。

## CommonJS

```js
// a.js
module.exports = { foo: 1 }

// b.js
const a = require('./a')
```

特点：

- 运行时加载。
- 同步 require。
- 适合服务端文件系统环境。

## ES Module

```js
// a.js
export const foo = 1

// b.js
import { foo } from './a.js'
```

特点：

- 静态结构。
- 支持 tree-shaking。
- live binding。
- 顶层 `import/export`。

## 面试官可能追问

### CommonJS 和 ESM 的核心区别？

- CommonJS 是运行时加载，ESM 是编译期静态分析。
- CommonJS 输出值，ESM 是 live binding。
- CommonJS 同步加载，ESM 支持异步加载和静态优化。

### 为什么 ESM 更适合 tree-shaking？

因为 ESM 的 `import/export` 是静态语法，构建工具可以在编译阶段分析哪些导出未被使用。

### 循环依赖怎么处理？

两者都能处理循环依赖，但行为不同。CommonJS 可能拿到未完全初始化的导出对象，ESM 通过 live binding 暴露绑定但仍受初始化顺序影响。

## 常见错误回答

- 只说 `require` 和 `import` 写法不同。
- 不知道 ESM 是 live binding。
- 不知道 tree-shaking 依赖静态结构。
