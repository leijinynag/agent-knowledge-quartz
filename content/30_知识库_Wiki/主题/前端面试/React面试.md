# React面试

## 重点范围

- JSX
- 组件生命周期
- Hooks
- useEffect / useLayoutEffect
- useMemo / useCallback
- React diff
- Fiber
- 状态管理
- 性能优化
- React 18 并发特性

## 高频问题占位

- [ ] 为什么 hooks 不能条件调用？
- [ ] useEffect 和 useLayoutEffect 区别？
- [ ] React diff 的核心策略？
- [ ] Fiber 解决了什么问题？
- [ ] React 性能优化有哪些层次？

## 面试准备方式

React 题要准备“API 使用版”和“原理版”两套回答。框架原理题要能画出更新流程。
