# 前端性能优化

## 重点范围

- 首屏性能
- 白屏时间
- LCP / FCP / CLS / INP
- 包体积优化
- 懒加载 / 预加载
- 图片优化
- 缓存策略
- 长列表优化
- React / Vue 渲染优化
- 性能监控与指标体系

## 回答框架

1. 先定义指标：慢在哪里，如何量化。
2. 再定位链路：网络、资源加载、JS 执行、渲染、接口。
3. 给出优化手段：加载优化、执行优化、渲染优化、缓存优化。
4. 最后说明监控和持续治理。

## 高频问题占位

- [ ] 首屏慢如何排查？
- [ ] 白屏如何定位？
- [ ] 如何优化包体积？
- [ ] 大列表如何优化？
- [ ] Core Web Vitals 是什么？

## 项目表达提示

性能优化最好准备真实指标：优化前后耗时、包体积、错误率、转化率或用户体验指标。
