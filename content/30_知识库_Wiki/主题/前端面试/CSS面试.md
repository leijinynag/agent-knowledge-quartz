# CSS面试

## 重点范围

- 盒模型
- BFC
- Flex / Grid
- 水平垂直居中
- position 与层叠上下文
- 响应式布局
- CSS 动画
- CSS Modules / scoped CSS / CSS-in-JS

## 高频问题占位

- [ ] 标准盒模型和 IE 盒模型区别？
- [ ] 什么是 BFC？怎么触发？有什么用？
- [ ] Flex 常用属性和布局原理？
- [ ] z-index 为什么有时不生效？
- [ ] 如何实现响应式布局？

## 面试准备方式

CSS 题要多配图、多写最小 demo，并积累“为什么线上样式不生效”的排查经验。
