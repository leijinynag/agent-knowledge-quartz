# Agent评估与可观测性

## 重点范围

- Eval 数据集
- Rubric / Outcome
- Trace / event log
- Tool call 记录
- 成本与 token 监控
- 成功率 / 失败率
- 回放与复现
- 人工审核

## 面试表达要点

Agent 不能只看“最后回答像不像”，还要观察过程：用了哪些工具、是否绕路、是否产生错误、是否可恢复、是否符合权限策略。
